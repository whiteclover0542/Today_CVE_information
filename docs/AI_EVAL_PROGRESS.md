## 참고

- 실행 로그·개별 리포트는 `scripts/eval/reports/`에 쌓인다(git 미추적). Claude 독립 채점 결과는 `claude-judge-*` 접두어 — 1차 원본은 2차 채점 시 실수로 덮어써져 유실됐고(평균 수치는 `docs/AI_EVAL_REPORT.md`에 보존), `CLAUDE_JUDGE_GUIDE.md`에 재발 방지용 백업 지침을 추가했다.
- API 키는 실행 시 환경변수로만 전달했고 어떤 파일에도 저장하지 않았다.
- `scripts/eval/refresh-generation-golden-outputs.mjs`: 프롬프트를 고칠 때마다 golden/generation.json을 최신 출력으로 갱신하는 유틸(이번에 새로 만듦, 앞으로도 재사용 가능).
